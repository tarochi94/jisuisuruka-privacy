サポート・お問い合わせ

電子レンジで作れる献立と買い物リストを提案し、自炊できた日を記録するiOSアプリです。

プライバシーポリシーご質問・不具合の報告（GitHub Issues）

GitHub Issuesは公開されます。個人情報や公開したくない記録は投稿しないでください。不具合の報告にはアプリのバージョン、iOSのバージョン、発生した操作を添えてください。保存データは自動送信されません。

よくある質問

記録や献立はどこに保存されますか？

端末内に保存されます。アカウント登録やクラウド同期はありません。アプリを削除すると保存データも削除されます。

広告や通知の設定を変更できますか？

夕食前の通知はアプリの設定で変更できます。対象地域で必要な場合は「広告のプライバシー設定」も表示されます。トラッキングの許可はiOSの設定で変更できます。

食物アレルギーに対応していますか？

避けたい食材の設定はアレルギー対応を保証しません。調味料を含む原材料表示を確認してください。加熱時間は目安であり、容器・食材量・電子レンジにより異なります。

집밥할까｜전자레인지 식단·장보기

전자레인지 식단과 장보기 목록을 제안하고 직접 해 먹은 날을 기록하는 iOS 앱입니다.

개인정보 처리방침문의·문제 신고 (GitHub Issues)

GitHub Issues의 게시물은 공개됩니다. 개인정보나 공개하고 싶지 않은 기록을 게시하지 마세요. 문제 신고 시 앱 버전, iOS 버전, 문제가 발생한 동작을 알려 주세요. 저장된 데이터는 자동 전송되지 않습니다.

자주 묻는 질문

기록과 식단은 어디에 저장되나요?

기기에 저장됩니다. 계정 등록이나 클라우드 동기화는 없습니다. 앱을 삭제하면 저장된 데이터도 삭제됩니다.

광고와 알림 설정을 변경할 수 있나요?

저녁 식사 전 알림은 앱 설정에서 변경할 수 있습니다. 해당 지역에서 필요할 때 광고 개인정보 설정도 표시됩니다. 추적 허가는 iOS 설정에서 변경할 수 있습니다.

식품 알레르기를 지원하나요?

피하고 싶은 재료 설정은 알레르기 대응을 보장하지 않습니다. 조미료를 포함한 원재료 표시를 확인해 주세요. 가열 시간은 참고용이며 용기, 식재료 양, 전자레인지에 따라 달라집니다.

自己煮吧｜微波菜單與採買

推薦微波料理菜單與採買清單，並記錄自己煮飯日子的 iOS App。

隱私權政策問題與錯誤回報（GitHub Issues）

GitHub Issues 的發布內容會公開顯示。請勿發布個人資料或不想公開的紀錄。回報問題時請提供 App 版本、iOS 版本及發生問題時的操作。儲存資料不會自動傳送。

常見問題

紀錄和菜單儲存在哪裡？

資料儲存在裝置上，沒有帳號註冊或雲端同步。刪除 App 時也會刪除儲存資料。

可以變更廣告與通知設定嗎？

晚餐前通知可在 App 設定中變更。在適用地區需要時，也會顯示廣告隱私設定。追蹤許可可在 iOS 設定中變更。

是否適用於食物過敏者？

想避開的食材設定不保證適用於食物過敏者。請確認包括調味料在內的原料標示。加熱時間僅供參考，會因容器、食材量與微波爐而異。
